# Курсовой проект на XeLaTeX

LaTeX-версия курсовой работы по теме генерации названий растений и аграрных объектов виртуальных миров.

Главный файл проекта — `main.tex`. Для компиляции используется **XeLaTeX**: он нужен для корректной работы с русским текстом и шрифтами OpenType.

## Быстрый запуск

### Локально

Установите TeX Live или MiKTeX с XeLaTeX и `latexmk`, затем в корне проекта выполните:

```bash
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

Готовый файл появится как `main.pdf`. Также доступна команда `make pdf` (если установлен Make).

Для очистки временных файлов:

```bash
make clean
```

### Overleaf

1. Создайте проект через **New Project → Upload Project** и загрузите ZIP-архив целиком.
2. В **Menu → Compiler** выберите **XeLaTeX**.
3. В качестве главного документа укажите `main.tex`.
4. Нажмите **Recompile**. При необходимости повторите компиляцию, чтобы обновилось оглавление.

## Структура проекта

```text
main.tex                 титульный лист и главный файл
preamble.tex             настройки шрифтов, полей, интервалов и оформления
latexmkrc                параметры автоматической сборки
Makefile                 команды make pdf / make clean
chapters/                введение, две главы, заключение, источники и приложения
code/                    девять Python-фрагментов для листингов
figures/                 эмблема университета и два скриншота интерфейса
main.pdf                 собранная версия работы
```

## Как редактировать

- Данные титульного листа и тему меняйте в начале `main.tex` в командах `\newcommand`.
- Текст работы редактируется в отдельных файлах каталога `chapters/`.
- Код листингов хранится в `code/listing_*.py`.
- Изображения находятся в `figures/`; при замене изображения сохраните его имя или измените путь в соответствующем `.tex`-файле.
- Общие параметры оформления меняются в `preamble.tex`.

Преамбула сначала использует PT Serif, PT Sans и PT Mono, а если они недоступны в системе сборки — переключается на шрифты TeX Gyre.
